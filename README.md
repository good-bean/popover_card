# Popover examples and work

Using built-in browser-supported popover attributes, I created a card grid where each provides the ability to view more info in a popover box. This is specifically to solve a problem in my GIT 450 course where I am a project manager for a team of web devs.

This includes the popover examples researched from the sites below:
- [Build an interactive hovercard](https://developer.chrome.com/docs/modern-web-guidance/guides/ui-components/hovercard)
- [`popover` HTML global attribute](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/popover)

There is CSS animation, but is only available for those with `prefers-reduced-motion` set to `no-preference` so that it is accessible by default.

Use freely at your own discretion.
